- **Fraud detection engine** (freelance, client confidential): scores a betting operator's daily sign-ups for fake accounts, multi-accounting and bonus abuse from email signals: disposable and typosquatted domains, username clustering, sign-up bursts. 100,000 accounts in about 11 seconds, in Excel/VBA, with automated tests.
